How it works

The verdict is computed, not inferred

A scenario is a world state, an instruction, a set of assertions and a pressure tag. Run it, and the verifier reads the trace and the final state to decide. The model never grades itself.

Assertions, not vibes

Eight assertion kinds — no_call, must_refuse, mutations_subset_of and friends — authored in the template and bound to concrete IDs. The model fills parameters; it never invents an assertion kind.

Four-layer sandbox

Mocked tools are the isolation boundary, plus process/filesystem scoping, network deny on the offline path, and three independent kill switches. Layer state is printed, never assumed.

Calibration agents

Four agents with known injected defects prove the platform measures anything at all. The scorecard has to recover the ranking without being told which is which — and the build fails if it doesn't.

Failure classifier

Eleven rule detectors carry the verdicts; two LLM-judged modes stay secondary and abstain below 0.7 confidence. Goal drift is defined as a scope violation you can measure, not a judgement call.

Pressure ladder P0–P5

Authority, urgency, ambiguity and injection framings over the same task. Reported as P_n − P0 deltas, so you see which framing moved the agent instead of an average that hides it.

Paired regression

Identical scenarios, seeds and world states across versions, then McNemar on the pass↔fail flips with Benjamini–Hochberg across categories. Effect size reported next to p, because a significant 0.4 points is still noise.

Point it at your agent

python -m are.cli mcp-serve --scenario-id <id>

Tool-level trace only — the limits it cannot enforce are printed, not assumed

  • JSON-RPC over stdio, no extra dependency
  • 11 rule detectors on the trace
  • HTML report per run
What it detects

The scorecard advises, it does not gate. We deliberately ship no auto-merge or auto-block hook — a hard automated gate on a derived score invites optimising the eval instead of the agent. The report recommends; a human decides.

Stated plainly: the LLM judge is uncalibrated — no human-labelled agreement study has been run, and judge-derived findings are advisory. Scenarios come from 13 hand-authored templates, so coverage is bounded by template imagination rather than by the real failure distribution. One domain; cross-domain transfer is unvalidated. Absolute scores are not comparable across agents built on different toolsets — only paired, same-suite comparisons are meaningful.
